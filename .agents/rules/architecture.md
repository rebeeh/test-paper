# Architecture & Decision Memory

- **Consult `docs/ARCHITECTURE.md` First**: At the start of every session or task involving codebase structure, always consult [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md) first before performing broad directory listings or multi-file grep searches. This saves context tokens and preserves continuity.
- **Record Key Decisions**: Whenever adding, modifying, or refactoring modules, styling systems, navigation layouts, or technical architectures, record the decision and rationale under the Architecture Decisions section of [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md).
- **Proactive Maintenance**: Prompt or proactively update [`docs/ARCHITECTURE.md`](../../docs/ARCHITECTURE.md) at the end of significant feature work or changes to keep the architecture snapshot fresh and accurate.
